# 필립모리스(PMI) 글로벌 사업 전략 동향 — Bedrock AI 분석 페이지

## 1. 개요

필립모리스 인터내셔널(Philip Morris International, PMI)의 글로벌 사업 전략
동향을 수집·분석·요약하여 보여주는 AI 기반 웹 페이지를 구축한다.
Amazon Bedrock의 LLM을 활용하여 뉴스·공시·전략 자료를 요약하고,
전략 테마별 인사이트를 자연어로 제공한다.

- **대상 기업**: Philip Morris International (PMI)
- **목적**: 글로벌 사업 전략 동향 파악 및 요약
- **핵심 기술**: Amazon Bedrock (생성형 AI)
- **산출물**: AI 분석 대시보드 웹 페이지

## 2. 배경 및 목표

### 2.1 배경
- PMI는 전통 담배 사업에서 **무연 제품(Smoke-Free Products)** 중심으로
  사업 포트폴리오를 전환하는 "Smoke-Free Future" 전략을 추진 중이다.
- IQOS, ZYN 등 신제품과 M&A, 지역별 규제 대응 등 전략 변화가 빠르게 일어난다.
- 분산된 정보를 사람이 일일이 추적하기 어려우므로, AI로 자동 요약·분석한다.

### 2.2 목표
- 다양한 소스의 전략 관련 정보를 **한 페이지에서 파악**한다.
- Bedrock LLM으로 **핵심 요약, 전략 테마 분류, 트렌드 인사이트**를 생성한다.
- 사용자가 자연어로 질문하면 AI가 답변하는 **Q&A 인터페이스**를 제공한다.

## 3. 주요 분석 영역 (전략 테마)

| 테마 | 설명 |
|------|------|
| 무연 제품 전환 (Smoke-Free) | IQOS, 가열담배, 전자담배 등 비연소 제품 전략 |
| 니코틴 파우치 / ZYN | 구강용 니코틴 제품 성장 및 미국 시장 전략 |
| 지역별 시장 전략 | 미국·EU·아시아·신흥시장별 규제 대응 및 확장 |
| M&A 및 투자 | 인수합병, R&D 투자, 포트폴리오 다각화 |
| ESG / 규제 대응 | 지속가능성, 공중보건 규제, 투명성 전략 |
| 재무 성과 | 매출/수익 구조, 무연 제품 매출 비중 추이 |

## 4. 기능 요구사항

### 4.1 전략 동향 요약
- 입력된 뉴스/공시/보고서 텍스트를 Bedrock으로 요약한다.
- 전략 테마별로 자동 분류하여 표시한다.

### 4.2 AI 인사이트 생성
- 수집된 정보를 바탕으로 "주요 변화", "시사점", "리스크"를 자동 생성한다.

### 4.3 자연어 Q&A
- 사용자가 "PMI의 미국 시장 전략은?" 등으로 질문하면 AI가 답변한다.

### 4.4 대시보드 시각화
- 전략 테마별 비중, 시간별 동향 추이 등을 차트로 표시한다.

## 5. 아키텍처 (Amazon Bedrock 기반)

```
[사용자 브라우저]
      │
      ▼
[웹 프론트엔드 (HTML/JS 대시보드)]
      │  REST / HTTPS
      ▼
[API Gateway] ──► [AWS Lambda]
                      │
                      ▼
              [Amazon Bedrock]
          (Claude / Titan 등 LLM 호출)
                      │
          ┌───────────┴───────────┐
          ▼                       ▼
   [요약 / 분석 처리]      [Knowledge Base (선택)]
                          (S3 + 벡터 검색, RAG)
```

### 5.1 구성 요소
- **프론트엔드**: 정적 웹 대시보드 (HTML/CSS/JS). 전략 동향·요약·Q&A UI.
- **API Gateway + Lambda**: 프론트엔드 요청을 받아 Bedrock 호출을 중계.
- **Amazon Bedrock**: 요약·분석·답변 생성용 LLM (예: Anthropic Claude, Amazon Titan).
- **Knowledge Base (선택)**: PMI 관련 문서를 S3에 저장하고 벡터 검색으로
  RAG(검색 증강 생성)를 수행하여 근거 기반 답변 제공.

### 5.2 Bedrock 모델 선택 (예시)
- 요약·분석·Q&A: Anthropic Claude 계열 (한국어/영어 요약 품질 우수)
- 임베딩(RAG 사용 시): Amazon Titan Embeddings

## 6. 데이터 소스 (예시)
- PMI 공식 IR 자료 및 연차/분기 보고서
- 보도자료 및 글로벌 뉴스
- 산업 분석 리포트
- 규제 기관 발표 자료

> 실제 구현 시 각 소스의 **이용 약관 및 저작권**을 준수하고, 수집·활용에
> 대한 법적 검토가 필요하다.

## 7. 구현 로드맵

1. **1단계 — 정적 대시보드 UI**: 샘플 데이터로 전략 테마·요약·차트 레이아웃 구성
2. **2단계 — Bedrock 연동**: Lambda + API Gateway로 요약/Q&A API 구현
3. **3단계 — RAG 적용**: Knowledge Base 구성, 근거 기반 답변 강화
4. **4단계 — 자동 수집**: 데이터 소스 수집 파이프라인 및 주기적 업데이트

## 8. 보안 및 고려사항
- Bedrock 호출은 **서버사이드(Lambda)** 에서 처리하고, AWS 자격 증명을
  프론트엔드에 노출하지 않는다.
- IAM 최소 권한 원칙 적용 (Bedrock InvokeModel 등 필요한 권한만 부여).
- 생성형 AI 결과는 **참고용**이며, 투자/경영 판단의 근거로 쓸 때는 원문 검증 필요.
- 외부 데이터 수집 시 저작권·약관 준수.

## 9. 비용 참고
- Bedrock 비용은 모델별 토큰 사용량 기준으로 과금된다.
- 정확한 요금은 AWS Bedrock 요금 페이지 및 AWS Pricing Calculator에서 확인한다.
